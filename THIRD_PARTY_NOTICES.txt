# Third party notices

The BLOOM application includes small, CSS-only adaptations of React Bits Blur Text,
Fade Content, and Spotlight Card by David Haz. Official JavaScript + CSS source was
reviewed on 2026-11-22. The original components use dynamic animation styles. These
adaptations deliberately reduce their APIs and use fixed classes, native CSS and
IntersectionObserver to follow the project's CSS policy, preserve readable SSR
content and respect reduced motion. Motion and GSAP are not required by these
adaptations. The fixed Spotlight effect is a hover/focus treatment, not a pointer
tracking light.

Sources:

- https://reactbits.dev/text-animations/blur-text
- https://reactbits.dev/animations/fade-content
- https://reactbits.dev/components/spotlight-card
- https://github.com/DavidHDev/react-bits/tree/main/src/content
